Dynamo · paper companion

A clock records causal history

Figure 3 clocks and branches match the paper. Cart contents attached to those clocks are invented teaching examples, not an Amazon production trace.

Each version carries a map from coordinating node to counter. A counter records updates coordinated there, not elapsed time. To compare clocks, treat missing nodes as zero. One clock descends from another if every counter is at least as large and at least one is larger.

If each clock has a counter larger than the other's, neither contains all the other's history. Keep both versions: these are concurrent siblings. The application decides how to reconcile their meaning.
