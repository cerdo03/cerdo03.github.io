Start here

Four modules, in order.

  1. LLM Inference: Foundations & KV Cache

    • Interactive guide
    • No prerequisite

    Explore tokens, prefill, decode, attention, cache memory and prefix reuse through interactive diagrams. These simplified simulations build intuition; they do not run a real model or measure performance.

    Built while studying PagedAttention, the Hugging Face cache guide and vLLM prefix caching. Covers prerequisites and related mechanisms, not the entire paper.

  2. Attention Mechanisms & KV-Cache Internals

    • Interactive module
    • 5 lessons
    • After Module 1

    Derive scaled dot-product attention, trace tensor shapes through multi-head, multi-query and grouped-query attention, and calculate how much memory the KV cache needs. Worked examples use invented toy numbers; memory figures count raw KV storage only.

    Built while studying Attention Is All You Need, Fast Transformer Decoding, GQA and the vLLM documentation.

  3. GPU Architecture and Performance Engineering

    • 5 lessons
    • After Module 2

    Map work to threads and memory, derive tiled matrix traffic, explore arithmetic intensity and roofline bounds, then compare prefill and decode by workload. Browser-based analytical models; no GPU required and no speedup measured.

  4. Efficient Attention and Memory

    • 5 lessons
    • After Module 3

    Derive online softmax, follow attention tile residency and IO, then resolve KV block tables, sharing and copy-on-write. Computed CPU teaching models; no GPU or measured speedup.

Optional companions

Use when you need them, then return to the path.

  • Module 0 · Mathematical Notation for Systems Engineers

    • Optional toolkit
    • 6 lessons

    Notation, indices, tensor shapes and stable softmax, connected to the attention equations. Optional checks explain mistakes without scores or navigation gates.

  • Transformer Architecture Explorer

    • Visual companion
    • Pairs with lessons 2.1–2.3

    Open a causal decoder in 3D, trace Q/K/V and head sharing, and inspect exact tensor shapes. Residual paths, FFN and memory details are optional previews; this schematic runs no pretrained model.
