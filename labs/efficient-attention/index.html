Three different kinds of block

The same word appears in computation, execution and storage. Keep their roles separate.

Attention tile
A patch of query/key pairs processed together.
CUDA thread block
A group of GPU threads assigned together to an SM.
KV block (page)
A storage unit holding K/V for a fixed number of processed token positions. Not a group of threads.
Materialize
Write an intermediate array to memory so a later operation can read it.
Workspace
Temporary storage used during computation.
Persistent cache
Stored K/V retained between generation steps.
