Starting this journal

11 October 2026 · Site note

This journal is a place to collect what I read, learn, build, and think about: books, personal reflections, technical experiments, and websites that make an idea easier to understand.

What belongs here

A book that stays with me. An observation from everyday life. A question worth investigating. An explanation that finally clicks. A small project that helps me test an idea. Each entry can be short; the aim is to keep a useful record.

Learning by building

The learning sites section will collect interactive examples as I publish them. Each will include a short description of the idea it explores.
